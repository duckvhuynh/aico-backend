# AICO-007 Preview Isolation Threat Test Plan

## Status, authority, and scope

This document is the **proposed adversarial and evidence contract** for
[aicompanyos#7](https://github.com/duckvhuynh/aicompanyos/issues/7), decision child
[aico-backend#20](https://github.com/duckvhuynh/aico-backend/issues/20), proof child
[aico-backend#21](https://github.com/duckvhuynh/aico-backend/issues/21),
`A7-THREAT-01`, and the test portion of `A7-TRACE-01`. It covers TD-008, PRD-FR-040--041,
SRS-FR-059--060, SRS-NFR-014, and the architecture slice of AT-014. It reuses the
AICO-003 non-disclosure/tenant/object rules and the AICO-004 exact-output manifest,
checksum, bounded-evidence, and cleanup rules.

The proof-child AICO-007 claim is deliberately bounded: a deterministic static fixture can be
served on the selected browser and service boundary while generated code cannot
obtain control-plane identity, storage, API data, credentials, or another preview.
It is architecture proof, not a production Preview Service, founder UX, release
security pass, or complete AT-014 result. Architecture text alone is not passing
evidence.

Decision child #20 owns only the proposed ADR, contract/schema, threat/AEO/trace
documents, strict structural validator, and its in-memory document/schema mutation
probes. It neither runs the hostile browser/service fixture nor executes any
`A7-T-*` case or real `A7-M-*` control mutation. Only proof child #21 may implement
and run the executable fixture, cases, real mutations, cleanup, and evidence bundle;
parent AICO-007 cannot complete until that proof is accepted.

Stable IDs in this plan are permanent. Removing, renaming, combining, or skipping a
case requires Architecture and Security/QA review, an updated trace, and a complete
rerun. The executable registry MUST equal the IDs in this document exactly. Unknown,
skipped, flaky, unsupported, unobserved, or cleanup-incomplete results fail the
applicable gate.

## Selected boundary under test

The cases test the following selected decision as one indivisible contract:

1. Control and preview use different schemeful registrable sites. Each immutable
   `PreviewVersion` receives one opaque, at-least-128-bit, never-reused hostname and
   origin of the form `p-<public-id>.<environment>.preview.<separate-site>`. A rebuild
   receives a new hostname. Unknown `Host` values never reach a default preview.
2. Preview is top-level/new-tab only. The control UI opens it with
   `noopener,noreferrer`; preview responses deny all framing. Generated content is
   never placed in a same-origin or privileged control-plane frame.
3. A signed, short-lived, one-time exchange capability binds server-authoritative
   tenant, Preview Version, successful Build and Artifact Versions, aggregate and
   per-file manifest digests, audience, expiry, revocation epoch, nonce, key version,
   policy version, and the origin/isolation/header/cache profile digests. The control
   UI opens `https://<exact-preview-host>/__aico/bootstrap#<capability>` with
   `noopener,noreferrer`. A fixed platform bootstrap removes the fragment with
   `history.replaceState`, POSTs a bounded body to same-origin `__aico/exchange`, and
   never loads generated files. Successful exchange consumes the nonce atomically, sets only
   a `__Host-aico_preview` cookie with `Secure; HttpOnly; SameSite=Strict; Path=/`, no
   `Domain`, and lifetime no longer than the grant, then redirects to a clean URL
   before generated bytes execute. Every later GET/HEAD reauthorizes the complete
   tuple from PostgreSQL; the token and cookie are references, never tenant authority.
4. The preview role exposes only capability exchange and manifest-backed GET/HEAD.
   It has a narrow preview/object identity, no control controllers, control session,
   general object key, production credential, or route to private control HTTP.
   Control authentication is also host-only, secure, HttpOnly, and SameSite=Strict;
   the private API has no preview CORS grant and rejects preview `Origin` and fetch
   metadata.
5. Publication accepts only an AICO-004 `SUCCESS` result after complete file-set,
   normalized-path, type, size, aggregate-manifest, and per-file SHA-256 verification.
   The immutable preview copy is tenant/build/manifest bound. A cold serve verifies
   the complete bounded file before releasing bytes; it never streams unverified
   prefixes.
6. The exact generated-content CSP is:

   ```text
   default-src 'none'; base-uri 'none'; object-src 'none'; frame-ancestors 'none'; form-action 'none'; connect-src 'none'; child-src 'none'; frame-src 'none'; worker-src 'none'; manifest-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; media-src 'self'; sandbox allow-scripts allow-same-origin
   ```

   It contains no `unsafe-inline`, `unsafe-eval`, wildcard, external host, `blob:`
   script/worker, reporting endpoint, or control/preview sibling source.
   The fixed bootstrap has a distinct immutable CSP: `default-src 'none'`, exactly
   one pinned inline-script hash, `connect-src 'self'`, and the same object, frame,
   child, worker, manifest, base, form, and frame-ancestor denials. Generated bytes
   never execute in the bootstrap document.

7. All generated responses also carry
   `Cross-Origin-Opener-Policy: same-origin`,
   `Cross-Origin-Embedder-Policy: require-corp`,
   `Cross-Origin-Resource-Policy: same-origin`,
   `Referrer-Policy: no-referrer`,
   `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`,
   `Origin-Agent-Cluster: ?1`,
   `X-Permitted-Cross-Domain-Policies: none`, and the exact deny-default
   `Permissions-Policy: accelerometer=(), ambient-light-sensor=(), autoplay=(), camera=(), display-capture=(), encrypted-media=(), fullscreen=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), midi=(), payment=(), picture-in-picture=(), publickey-credentials-get=(), screen-wake-lock=(), serial=(), usb=(), web-share=(), xr-spatial-tracking=()`, and no `Access-Control-Allow-Origin` or
   `Access-Control-Allow-Credentials`. TLS is mandatory and the preview zone carries
   its accepted HSTS policy.
8. Bootstrap, exchange, denial, HTML, script, style, media, and other authenticated
   responses use `Cache-Control: private, no-store, no-transform`,
   `Pragma: no-cache`, `Expires: 0`, `CDN-Cache-Control: no-store`, and
   `Surrogate-Control: no-store`. They return exact media type and byte length with
   no content negotiation, compression transform, attachment disposition, range,
   304, directory listing, or object-store redirect. Authorization and
   authenticated responses are never cached. An optional trusted server-side byte
   cache is populated only after authorization and integrity verification and is keyed
   by `(environment, public preview/version ID, manifest digest, normalized path,
content digest)`; it does not cache authorization.
9. Expiry or revocation first makes the Preview Version unavailable to every new
   authorization. Physical object/cache/metadata cleanup is asynchronous,
   tenant-scoped, idempotent, and tombstoned. An unknown cleanup result stays
   unavailable. Origins are never reused. Unavailable/expired/revoked cleanup
   responses use `Clear-Site-Data: "cache", "cookies", "storage"` where supported;
   this best-effort browser cleanup is never revocation authority.

The browser cannot be made to forget bytes already rendered, saved, screenshotted, or
copied. A top-level untrusted page can navigate itself or create a browser-local
`data:`/`blob:` download subject to browser policy. The claim is that it cannot use
those facts to regain authorization, reach the control context, obtain foreign bytes,
or make the platform serve an unsafe/unmanifested download. No DRM or recall claim is
made.

## Common deterministic protocol

The AICO-007 proof uses a **two-company** fixture: companies A and B have disjoint
founders, control sessions, successful builds, artifacts, manifest digests, preview
versions, origins, grants, cookies, object sets, storage canaries, and immutable body
markers. It also creates absent, failed, canceled, partial, tampered, expired,
revoked, stale-key, and stale-policy controls. Browser time, IDs, DNS, TLS, revocation
barriers, cache, object storage, private API, and outbound receivers are deterministic.

The fixture must use HTTPS origins on two different registrable `.test` sites through
a trusted disposable test CA. Its generated attack page is treated as hostile and
attempts each browser surface from real page JavaScript. Browser assertions alone are
insufficient: service, database, object, cache, DNS/network, cookie-name, control API,
event/outbox, provider/tool/sandbox, budget/cost, and cleanup ledgers reconcile the
result. Receivers retain destination class, method, count, and safe result class only;
they do not retain query strings, headers, bodies, tokens, or cookie values.

For every negative case the external result is the same empty `404` response family
as an absent opaque preview/path, with the same safe no-store/security-header class
and without tenant, preview, build, artifact, manifest, path, checksum, state, expiry,
revocation, policy, or key detail. A denial has **zero unauthorized effect**: no
session/grant issuance or renewal, nonce consumption except the one atomic winning
exchange, preview publication/copy/cache fill, object body release, control request
with identity, business mutation/success event/continuation, provider/tool/sandbox
invocation, budget reservation, charge, or cost. One bounded, redacted denial/security
counter is permitted and is not a business-success effect.

Authorized positive controls must return the exact manifest bytes and expected MIME
type through the same code paths. Repeating a case, changing an opaque ID, racing a
request, or using GET versus HEAD must not change foreign-resource disclosure. Each
case records before/after authoritative state and all side-effect counts. A foreign tenant
or preview never becomes visible merely because an opaque host, path, grant, or browser
state is syntactically valid.

## Proof-child command and evidence contract

Proof child #21's smallest executable fixture is internal, deterministic, synthetic, and
**paid-service-free**. It runs as one bounded foreground command, starts only attached
disposable services, uses no production or paid credential/service, and removes its
DNS entries, trusted test CA material, processes, browser contexts, containers,
networks, volumes, object data, cache entries, and temporary files before exit. The
fixture preview process is excluded from `AppModule`, production builds, public
routes, and normal runtime entry points.

Decision child #20 does not run this command. Its structural validator may parse this
registry and mutate in-memory document/schema copies only; that validates the closed
specification, not any browser/service control or real mutation.

The pass manifest contains only schema version, exact Git SHA and clean-state result,
case ID/result/reason class, fixture/header/runtime/browser/image digests, safe origin
classes, counts and duration buckets, aggregate/per-file expected-versus-actual hash
results, redaction/drop counts, side-effect totals, cleanup result, and evidence-file
digests/sizes. It is labeled `ARCHITECTURE_TEST_ONLY`; it is not production or release
evidence.

Raw capability/token/cookie/URL/query/referrer/header values, generated/control/foreign
bodies, object keys, host filesystem paths, source maps, browser profiles, HAR files,
screenshots, console text, storage values, credentials, private API responses, foreign
IDs/metadata, stack/SQL, and unbounded CSP reports are prohibited. Browser/network
capture is asserted in memory and serialized only into safe classes and counts. If a
serializer or redactor cannot prove safety, it drops the diagnostic and fails the
proof rather than retaining the payload.

## Non-waivable exit rule and explicit limitations

Decision child #20 can be accepted only when the strict structural validator, all 12
document mutation probes, canonical verification, and hosted CI pass on the same exact
clean semantic revision; attributable Architecture/Security and Product/Platform owners
accept that SHA; and later proof/production gaps remain open under their named issues.
Parent AICO-007 can complete only after proof child #21 passes all 39 stable executable
cases, all 12 real control mutations, exact-final-SHA hosted CI, and attributable
QA/Security review. Any semantic change requires fresh applicable decisions and proof.

Any same-site control/preview deployment, host reuse, control cookie/storage/API data,
foreign preview/tenant byte, signed-access confusion, unverified or mixed build byte,
outbound/private request with identity, opener/frame escape, executable MIME/CSP
bypass, authenticated cache reuse, post-expiry/revocation authorization, fabricated
cleanup success, prohibited evidence value, or unexplained residue is Critical and
non-waivable. The candidate is killed or paused, safe evidence is preserved, and the
entire matrix and mutations rerun after correction.

This plan does not promise to prevent a founder from copying already displayed
content; prevent all self-navigation, popup, or local blob/data creation by top-level
generated code; erase browser pixels/history already received; make arbitrary
generated code trustworthy; serve generated backends; enable runtime egress; provide
real auth/payment/email/analytics/deployment; or establish formal accessibility or
production readiness. The preview remains an untrusted static prototype.
